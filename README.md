# Week 12: Arduino PlatformIO + GitHub

โปรเจกต์ตัวอย่าง: LED กระพริบพร้อมแสดงสถานะผ่าน Serial Monitor

## เปิดและทดสอบ
1. เปิดโฟลเดอร์นี้ใน VS Code ที่ติดตั้งส่วนเสริม PlatformIO IDE
2. ค่าเริ่มต้นเป็น Arduino Uno: กด Build (เครื่องหมายถูก) เพื่อคอมไพล์
3. ถ้าใช้ ESP32 DevKit ให้เลือก environment `esp32dev` ใน PlatformIO Project Tasks แล้วกด Build ใต้ environment นั้น
4. ต่อสาย USB ที่รับส่งข้อมูลได้ แล้วกด Upload ของ environment ที่ตรงกับบอร์ด
5. เปิด Serial Monitor ที่ 9600 baud จะเห็น LED ON / LED OFF
6. ESP32 แต่ละรุ่นใช้ LED คนละขา บางรุ่นไม่มี LED ในตัว โค้ดตัวอย่างใช้ GPIO 2 สำหรับ ESP32 DevKit แบบทั่วไป ให้ตรวจรุ่นบอร์ดก่อน Upload; ESP32-S3/C3 ต้องเปลี่ยน board ID ให้ตรงรุ่น

## แสดงการแก้ไขโค้ด
`before/main.cpp` คือโค้ดเริ่มต้นที่สลับสถานะทุก 1000 ms
`src/main.cpp` คือโค้ดหลังปรับให้สลับสถานะทุก 300 ms
ดังนั้นคาบการกระพริบหนึ่งรอบเปลี่ยนจาก 2 วินาทีเป็น 0.6 วินาที
ใช้ millis() เพื่อให้โปรแกรมไม่ต้องหยุดรอด้วย delay()

เมนู 5 ใน START-WEEK12.cmd สร้าง Git repository พร้อมสอง commits จากโค้ดก่อนและหลัง และถามชื่อ/อีเมลของคุณเมื่อยังไม่มี Git identity
สร้าง repository ว่างบน GitHub ของตัวเอง แล้วใส่ URL ในเมนู 5 เพื่อ push
ห้ามใช้ repository URL ของอาจารย์ที่แสดงเป็นตัวอย่างในบทเรียน
การลงชื่อเข้าใช้ GitHub ให้ทำในหน้าต่าง sign-in ที่ Git เปิดขึ้นเอง

## สิ่งที่ใช้ส่ง
- ลิงก์ repository ของคุณบน GitHub
- หน้าประวัติ Commits และ diff ของการเปลี่ยน 1000 เป็น 300
- ภาพ Build SUCCESS และภาพ/วิดีโอการทำงานจริงเมื่อมีบอร์ด

โค้ดนี้เป็นงานตัวอย่างที่จัดเตรียมให้ ต้องตรวจผล Build และผลบนบอร์ดจริงของคุณก่อนอ้างว่าได้ทดสอบกับฮาร์ดแวร์
